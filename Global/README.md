# Playwright URL Checker （SA加盟店 判定アプリ）

指定したCSVファイルのURLを読み込み、それぞれのページに「SA加盟店」というテキストが存在するかを自動で判定するツールです。

## 前提条件
- Node.js がインストールされていること（v18以上推奨）

## 初回セットアップ方法

1. 必要なライブラリをインストールします。以下のコマンドをターミナルで実行してください。
   ```bash
   npm install
   ```

2. Playwright（ブラウザ自動化ツール）が使用するブラウザをインストールします。以下のコマンドを実行してください。
   ```bash
   npx playwright install
   ```

## 実行方法

以下のコマンドを実行すると、`sample-input.csv` を読み込んで処理を開始します。

```bash
node index.js sample-input.csv
```

## 入力CSV (`sample-input.csv`) について
- 文字コードは `UTF-8` で保存してください。
- 1行目はヘッダー行として扱われます。
- 必ず `url` という名前の列を含めてください。
- `id` や `store_name` など他の列が含まれている場合、それらも結果のCSVに引き継がれます。

## 結果について
処理が完了すると、コンソール画面に結果が表示されるとともに、同じフォルダに `result.csv` というファイルが作成されます。
